# Documentos da IA do VISTA Studio

Cada arquivo `.md` aqui é uma "receita" que o site manda para a IA junto com o pedido do usuário,
quando o pedido combina com as palavras da linha `palavras:` (sem acento, maiúscula ou minúscula tanto faz).
`sempre: sim` faz o documento ir em TODO pedido (deixe esses curtos).

Para ensinar algo novo à IA: crie um arquivo novo aqui seguindo o mesmo formato
(1ª linha `palavras: ...`, depois o texto com um exemplo COMPLETO de bloco ```acoes). Não precisa mexer em código.
Este README não é enviado.
